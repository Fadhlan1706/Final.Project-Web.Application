Tentang Proyek SkillSwap

SkillSwap adalah platform web kolaborasi skill antar mahasiswa. Platform ini memungkinkan mahasiswa saling menemukan partner berdasarkan keahlian, mengajukan request kolaborasi, serta mengelola proyek bersama melalui Kanban board interaktif.

Frontend dibangun dengan HTML, CSS, dan Vanilla JavaScript. Backend direncanakan menggunakan PHP native dan MySQL untuk autentikasi, manajemen data, dan API endpoint.
